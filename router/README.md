# router — маршрутизатор TIER 0/1/2

- `router.py` — ядро. Функция `route(code)` прогоняет код через детерминированный контур.
  - **TIER 0** (`tier0`): синтаксис (AST), импорты (словарь), security-паттерны. Поточечная гарантия (B1).
  - **TIER 1** (`tier1`): эвристик по ключевым словам с числом уверенности. Оценка, не гарантия (B2).
  - **TIER 2** (`tier2`): интерфейс к облачной LLM для soft-задач.
- `cloud.py` — вызов облачной модели за информационным барьером. Без ключа — заглушка.

Граница честности: TIER 0 даёт гарантию, TIER 1 — только оценку. Смешивать их статусы нельзя.
