# deterministic-ai-contour — двухконтурная схема для ИИ под ограничениями ИБ и железа

Рабочий минимум к статье **«Как внедрить ИИ под ограничениями ИБ и железа: что отдать детерминизму, а что — облачной модели с GPT и RAG»**.

Идея в одной фразе: требования «в каждом случае» (жёсткие) проверяем **детерминированно** — там есть гарантия; требования «можно иногда нарушить» (мягкие) отдаём **генеративной модели**. Большинство задач кодогенерации в узком домене закрывается детерминированным контуром за миллисекунды, без обращения к модели.

> **Статус.** Это методология и рабочий прототип, а не промышленный кейс с полевыми метриками. Код запускается без ключей и внешних зависимостей (чистый Python) — чтобы можно было «скачать и попробовать». Полный теоретический разбор со ссылками — в `THEORY.md`.

## Что внутри

| Папка | Что делает | Гарантия |
|---|---|---|
| `router/` | Маршрутизатор TIER 0/1/2: детерминированные проверки + интерфейс к облачной LLM | TIER 0 — поточечная (B1); TIER 1 — оценка (B2) |
| `audit/` | Информационный барьер (что можно слать в облако) и аудитор меток бенчмарка sound-оракулом | детерминированно |
| `benchmark/` | Прогон «где модель справляется»: pass-rate по сложности, счётчик AST-ошибок | — |
| `templates/` | Пример шаблона для «дыр» в покрытии модели | — |
| `tasks/` | Наборы задач для бенчмарка (JSON) | — |
| `tests/` | Тесты, проверяющие, что контур и аудитор работают | — |

## Быстрый старт

```bash
git clone https://github.com/SergeiUstiugov/deterministic-ai-contour
cd deterministic-ai-contour

# 1) тесты — убедиться, что всё работает (нужен только Python 3.10+)
python tests/test_core.py

# 2) аудитор меток бенчмарка (в примере одна метка специально неверна)
python audit/label_auditor.py audit/sample_dataset.json

# 3) бенчмарк «где модель справляется» (по умолчанию заглушка генерации)
python benchmark/benchmark.py --tasks tasks/tasks_ml.json

# 4) маршрутизатор на своём фрагменте кода — см. пример ниже
```

Пример работы маршрутизатора:

```python
from router.router import route

report = route("import cv2\nos.system('rm -rf /')\n")
print(report["decision"])
# -> BLOCK на TIER 0 (детерминированно, с гарантией): ...
```

## Подключение реальной модели (опционально)

Открытый контур рассчитан на **облачную LLM с GPT и RAG** (например, Perplexity), работающую **только с обобщениями за информационным барьером**. Конкретика объекта наружу не уходит — её отсекает `audit/ib_filter.py`. Почему это безопасно — см. статью-компаньон про асимметричный мост.

```bash
export PERPLEXITY_API_KEY=...        # ключ вашего провайдера
# затем раскомментируйте боевой вызов в router/cloud.py
```

Если ключа нет — всё работает на заглушке, детерминированный контур от модели не зависит.

## Принципы, на которых это стоит

- **TIER 0 (B1)** — детерминированная проверка с поточечной гарантией: AST-парсер (синтаксис), словарь импортов, security-паттерны. Важно: regex для security — это гарантия только для конкретного паттерна, а не «безопасности» вообще; в проде замените на AST/Semgrep.
- **TIER 1 (B2)** — быстрый эвристик с числом уверенности. Это **оценка, не гарантия**; число стоит калибровать (см. `THEORY.md`, раздел про conformal prediction).
- **TIER 2 (soft)** — облачная модель только для мягких задач, за информационным барьером.

Полное обоснование (∀ vs E[·], semiring, soundness ≠ completeness, обе стороны спора о галлюцинациях, список литературы с DOI) — в [`THEORY.md`](THEORY.md).
