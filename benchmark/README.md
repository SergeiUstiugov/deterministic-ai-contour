# benchmark — «где модель справляется»

`benchmark.py` прогоняет задачи кодогенерации через модель и считает pass-rate по сложности
плюс число синтаксических (AST) ошибок. Проверка результата — детерминированная
(AST + обязательные подстроки задачи).

Цель — не «оценить модель», а понять, что отдать модели (где справляется),
а что закрыть шаблонами/правилами (где нет). Наблюдение из статьи: модель почти не
ошибается синтаксически (0 AST), но падает на runtime — это и есть граница ∀ / E[·].

Задачи — в `../tasks/*.json`. По умолчанию генерация заглушена (запуск без ключа).
Реальную модель подключают через `router/cloud.py`.

Запуск: `python benchmark/benchmark.py --tasks tasks/tasks_ml.json`
