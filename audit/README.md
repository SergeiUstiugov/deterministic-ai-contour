# audit — барьер и аудитор меток

- `ib_filter.py` — информационный барьер. `screen(text)` возвращает найденную конкретику
  (IP, теги SCADA, номера установок, ФИО, давления, ключи). Пусто — запрос можно слать в облако.
- `label_auditor.py` — аудитор золотых меток бенчмарка sound-оракулом (BFS-достижимость).
  Принцип: где задача разрешима, метку проверяем детерминированно, а не «на доверии».
  В `sample_dataset.json` одна метка специально неверна — аудитор её ловит.

Запуск: `python audit/label_auditor.py audit/sample_dataset.json`
